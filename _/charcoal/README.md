# Charcoal native presentation

The `.charcoal` submodule pins android-NDK at
`3e682fb1175beef5625dbd2418730220e49fc9bd`. Initialize submodules before compiling
the renderer. Native drawing consumes its pure C color header; APK packaging
stages its window, splash and control resources beside the small fullscreen
Mathieu alias. There is no new framework, Java, Kotlin, Gradle or runtime palette
initialization.

Application background, text, controls, selection and error roles now follow
the shared contract. Dancer suits, forms, marker transport and mathematical
identity remain fixed. The Swords fill is a light warm neutral instead of the
former near-black brown so it remains visible on charcoal; all suit faces use
dark glyph ink for contrast. The other suit colors and their optional dot tints
are preserved. No mathematical action, checkpoint, journal, animation clock or
hit target changes.

The permanent development signer remains certificate
`f997a30170a967e073ab47e1212a71b3967ffe2e1e88d78d659c77bf085cb3fe` and versionCode
remains 2. It is not replaced by another application's public test signer.

The workflow executes actual ICK host mathematics/session/renderer tests, builds
three ABI packages, then exercises real native controls on API29/API34 in both
system night settings. Its observer samples the independent root and selected/
ordinary control roles, verifies a real posted frame, changes M12 to M24 through
touch and verifies M24 reopening. It also exercises same-candidate replacement.
The first posted frame/resize log is emitted only after a successful window post
when dimensions change; it does not add synchronous initialization.

Grease owns the new orchestration. Its calls to the existing canonical Bash APK
packager preserve that external packaging interface; no alternate packager or
shell implementation is introduced. The pinned provider supplies qualified ICK
frontends. NDK retains the existing foreign NativeActivity glue, assembly and
link boundary. Parser attempts and corrections are retained in syntax-attempts.txt.

Host pixels, signed artifacts, emulator execution and physical C67 are separate
results. API29/API34 checks are pending until the workflow completes. Full startup
transition, rotation/error-state coverage, prior-version migration and physical
C67 acceptance remain outstanding. No application is installed on a user device.
